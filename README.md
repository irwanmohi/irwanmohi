## 👨‍💻 About Me

I'm a hands-on systems administrator and IT consultant focused on **Linux server administration, web infrastructure, and security hardening**. I help government agencies and enterprises across Malaysia run, secure, and troubleshoot production infrastructure — with a strong interest in cybersecurity and defensive security research.

- 🐧 Day-to-day in **Ubuntu/Linux** environments — diagnostics, maintenance, and incident response
- 🔐 **Security &amp; compliance hardening** against industry benchmarks (e.g. CIS)
- ⚙️ **DevOps troubleshooting** across web hosting control panels and containerized stacks
- 🛡️ Exploring **exploit development, networking, and security research** (and writing about it)
- 📝 I write about infosec at [infosec-openmic.blogspot.com](https://infosec-openmic.blogspot.com/)
- 🗣️ Bilingual technical communication — **Bahasa Malaysia &amp; English**
